# Калькулятор инвестиционной привлекательности

Одностраничный калькулятор NPV, IRR, срока окупаемости (простого и дисконтированного) и PI.
Полностью статический сайт — весь расчёт выполняется в браузере на JavaScript, без сервера и без базы данных.

## Запуск локально

Просто откройте `index.html` в браузере. Никакой установки не требуется.

Либо через локальный сервер (удобнее для разработки, избегает CORS-ограничений на `file://`):

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub, например `investment-calculator`.
2. Запушить файлы этого проекта в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: investment calculator"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/investment-calculator.git
   git push -u origin main
   ```
3. В настройках репозитория → **Settings → Pages** → Source: ветка `main`, папка `/ (root)`.
4. Через пару минут сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/investment-calculator/`

## Языки и тема

- Переключатель языка (RU / KG / EN) — сейчас полностью переведён только русский, остальные временно дублируют русский текст (заготовка в `translations.js`, заполнить при добавлении переводов).
- Тема оформления: авто (по системным настройкам), светлая, тёмная — сохраняется в `localStorage`.
- Валюта: сом (по умолчанию) или доллары — влияет только на отображаемый символ, не на расчёт.

## Структура

- `index.html` — разметка
- `style.css` — стили, светлая/тёмная тема
- `translations.js` — словарь переводов
- `script.js` — расчёты (NPV, IRR методом бисекции, Payback, Discounted Payback, PI) и вся логика интерфейса
